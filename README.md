# 🎭 Face Mood AI

**Face Mood AI** is a real-time facial expression detection web application built with **React, Vite, and MediaPipe**. It uses your webcam to analyze facial landmarks and estimate expressions in real time.

## Live Demo: https://face-mood-ai.vercel.app/

## ✨ Features

* 🎥 Real-time face tracking
* 🧠 AI-powered facial expression detection
* 🕸️ Face mesh visualization
* 📊 Expression confidence scores
* 📸 Mood snapshots
* 🔊 Audio feedback
* 🎚️ Detection sensitivity control
* 📹 Camera switching
* ⛶ Fullscreen mode
* 📈 Mood history

## 🛠️ Tech Stack

* **React**
* **Vite**
* **JavaScript**
* **MediaPipe Tasks Vision**
* **HTML5 Canvas & WebRTC**
* **CSS3**

## 🚀 Getting Started

```bash
git clone https://github.com/amitx22/face-mood-ai.git
cd face-mood-ai
npm install
npm run dev
```

Open the local URL shown in the terminal and allow camera access.

## 🧠 How It Works

```text
Webcam
   ↓
MediaPipe Face Landmarker
   ↓
Facial Landmarks & Blendshapes
   ↓
Expression Analysis
   ↓
Real-Time Mood Display
```

## 🔐 Privacy

Face analysis is performed in the browser using MediaPipe. Camera access requires user permission.

> Expression detection is an estimation based on facial movements and should not be considered a definitive measure of a person's actual emotional state.
